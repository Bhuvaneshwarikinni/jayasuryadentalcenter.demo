# 🦷 Jayasurya Dental Center

A modern, responsive web application for a dental clinic, built with React, TypeScript, and Tailwind CSS. It provides patients with an intuitive interface to explore dental services, view doctor profiles, check clinic details, and book appointments.

## 🚀 Features

* **Modern UI & Components:** Built using a responsive design system with clean card layouts and sleek styling (`shadcn/ui` components).
* **Doctor Profiles:** Dedicated sections displaying dental specialists with adjusted layouts to ensure a seamless view across all screen sizes.
* **Services & Treatments:** Comprehensive breakdown of dental care services offered by the clinic.
* **Appointment Booking & Contact:** User-friendly forms and contact sections for easy patient inquiries.

## 🛠️ Tech Stack

* **Frontend Framework:** React (with Vite)
* **Language:** TypeScript
* **Styling:** Tailwind CSS
* **UI Components:** Shadcn UI
